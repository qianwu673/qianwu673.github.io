Qian Wu Homepage Template
=========================

This is a minimal GitHub Pages template.

Recommended file structure:

index.html                  English default homepage
assets/style.css            Shared style file
assets/profile.jpg          Your profile photo, not included here
en/notes.html               English essays and notes
zh/index.html               Chinese homepage
zh/notes.html               Chinese essays and notes
ja/index.html               Japanese homepage
ja/notes.html               Japanese essays and notes
posts/*.html                Individual article pages

How to use:
1. Upload all files and folders to your GitHub Pages repository.
2. Add your own photo to assets/profile.jpg.
3. Edit index.html, zh/index.html, ja/index.html, and the notes pages.
4. Keep assets/style.css as the shared design file.

Suggested photo:
- File name: profile.jpg
- Location: assets/profile.jpg
- Size: square photo, around 600x600 or 800x800
- File size: preferably under 500 KB
